# MOSt V16.63.3 No Auto Upgrade

Build `1.7.667`, based on V16.63.2.

This code-only workstation release disables the legacy database upgrader, the server/client version upgrader, and the shared `update\\fileversion.xml` auto-update path. It is intended to prevent a code-only workstation installation from entering the upgrade cycle.

The glasses formatting changes from V16.63.2 are included. Consultation letter and V16.64 third-party billing work are excluded.

Installer: `MOSt_V16.63.3_NO_AUTO_UPGRADE_XP.zip`
